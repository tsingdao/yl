程序结构：条件与循环

JavaScript 三大程序结构中的两种：条件结构（if…else、switch）按不同条件执行不同分支；循环结构（for、while、do…while、for…of）重复执行一段代码。每个卡片都可以点击"运行"查看真实执行结果。

一、条件结构

if…else if…else 多分支判断：成绩等级

var yl_score = 85; if (yl_score >= 90) { yl_grade = "优秀"; } else if (yl_score >= 80) { yl_grade = "良好"; } else if (yl_score >= 60) { yl_grade = "及格"; } else { yl_grade = "不及格"; }

点击按钮，查看命中的分支

switch 多值匹配：星期几

switch (yl_day) { case 1: yl_name = "星期一"; break; case 6: yl_name = "星期六"; break; case 7: yl_name = "星期日"; break; default: yl_name = "输入 1~7"; }

点击按钮，查看匹配结果

二、循环结构

for 循环 已知次数：1~100 求和

var yl_sum = 0; for (var yl_i = 1; yl_i <= 100; yl_i++) { yl_sum += yl_i; }

点击按钮，查看累加结果

while 循环 先判断后执行：找 7 的倍数（条件+循环嵌套）

var yl_i = 1, yl_list = []; while (yl_i <= 100) { if (yl_i % 7 === 0) { yl_list.push(yl_i); } yl_i++; }

点击按钮，查看筛选结果

do…while 循环 先执行后判断：5 的阶乘

var yl_i = 1, yl_result = 1; do { yl_result *= yl_i; yl_i++; } while (yl_i <= 5);

点击按钮，查看计算结果

for…of 循环 遍历数组：逐个取出元素

var yl_fruits = ["苹果", "香蕉", "橘子"]; for (var yl_f of yl_fruits) { yl_text += yl_f + " "; }

点击按钮，查看遍历结果
