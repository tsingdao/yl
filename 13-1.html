Font Awesome
字体图标

Font Awesome 使用字体图标（Icon Font）技术，将图标映射为 Unicode 字符，通过 CSS 伪元素或类名来显示图标。只需引入一个 CSS 文件和字体文件即可使用全部图标。

常用图标展示

Font Awesome 6 Free 版本 — 通过 .fas / .far / .fab 前缀调用

fas fa-heart
star
fas fa-star

fas fa-user
home
fas fa-home
search
fas fa-search
envelope
fas fa-envelope
